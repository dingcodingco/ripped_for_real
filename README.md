# Ripped For Real 💪

매일 동기부여 명언과 챌린지를 제공하는 피트니스 동기부여 Flutter 앱입니다.

## 📱 주요 기능

- **매일 동기부여 명언**: 엄선된 피트니스 명언으로 영감을 받으세요
- **30일 챌린지 시스템**: 체계적인 피트니스 챌린지로 진행 상황을 추적하세요
- **성취 시스템**: 성과를 달성하고 레벨업하세요
- **다국어 지원**: 한국어와 영어 지원
- **명언 저장**: 좋아하는 명언을 개인 컬렉션으로 저장
- **매일 알림**: 매일 동기부여를 놓치지 마세요
- **아름다운 UI**: 애니메이션 배경의 모던하고 깔끔한 인터페이스

## 🚀 시작하기

### 필수 요구사항

- Flutter SDK (^3.8.1)
- Dart SDK
- Android Studio / Xcode (모바일 개발용)

### 설치 방법

1. 저장소 클론
```bash
git clone https://github.com/dingcodingco/ripped_for_real.git
cd ripped_for_real
```

2. 의존성 설치
```bash
flutter pub get
```

3. 앱 실행
```bash
flutter run
```

## 📚 프로젝트 구조

```
lib/
├── l10n/              # 다국어 파일
├── models/            # 데이터 모델
├── screens/           # 앱 화면들
├── services/          # 비즈니스 로직과 서비스
└── widgets/           # 재사용 가능한 UI 컴포넌트
```

## 🛠️ 사용 기술

- **Flutter** - 크로스 플랫폼 프레임워크
- **Hive** - 로컬 저장소
- **Google Mobile Ads** - 수익화
- **Flutter Local Notifications** - 푸시 알림
