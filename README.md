# Ripped For Real 💪

A Flutter-based fitness motivation app that delivers daily inspirational quotes and challenges to help users stay motivated on their fitness journey.

## 📱 Features

- **Daily Motivational Quotes**: Get inspired with carefully curated fitness quotes
- **30-Day Challenge System**: Track your progress through structured fitness challenges
- **Achievement System**: Unlock achievements and level up as you progress
- **Multi-language Support**: Available in English and Korean
- **Save Favorite Quotes**: Build your personal collection of motivational content
- **Daily Notifications**: Never miss your daily dose of motivation
- **Beautiful UI**: Modern, clean interface with animated backgrounds

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (^3.8.1)
- Dart SDK
- Android Studio / Xcode for mobile development

### Installation

1. Clone the repository
```bash
git clone https://github.com/dingcodingco/ripped_for_real.git
cd ripped_for_real
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```
